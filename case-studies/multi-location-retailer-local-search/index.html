Local SEO Case Study: Regional home goods retailer (22 locations)

Rebuilt local landing pages and Core Web Vitals across 22 stores, moving map pack visibility and organic revenue in the same quarter.

Published November 4, 2025

  • Local SEO
  • Core Web Vitals & Site Performance
  • Technical SEO

Results

+164%

Map pack impressions

Across all 22 locations, 6 months post-launch

4.8s -> 1.9s

Mobile LCP

On the location page template

+41%

Organic-attributed store visits

Estimated via GA4 store locator conversion tracking

The challenge

22 near-duplicate location pages were competing with each other for the same local queries, and mobile LCP averaged 4.8s on the template driving most of the traffic.

The approach

Rebuilt the location page template with genuine per-store content and schema, cleaned up Google Business Profile data across every location, and cut the mobile LCP by optimizing hero imagery and removing render-blocking third-party scripts.

The full story

Each location page had been built from the same template with only the address and phone number swapped, which meant Google frequently couldn’t tell which of two nearby locations should rank for a given “near me” search — and sometimes suppressed both.

We rebuilt the template around real per-location content: local manager quotes, store-specific inventory highlights, and localized review schema pulled from each location’s actual Google Business Profile, backed by a citation cleanup pass to fix inconsistent NAP data across directories that had accumulated over several years of location openings and closures.

The performance work ran in parallel. The location template’s mobile LCP was being dragged down by an unoptimized hero carousel and a chat widget script loading render-blocking JS. Converting hero images to responsive AVIF, deferring the chat widget until after first interaction, and reserving layout space for it eliminated both the LCP and CLS problems on the same template.

“We went from location pages that were actively competing with each other to a system that lets a new store go live and start showing up in local search within weeks, not months.”

VP of Marketing, Regional home goods retailer
